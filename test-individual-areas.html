✅ Dashboard Dinâmico - Individual por Area Path

Demonstração de como o dashboard agora funciona com um card para cada area path selecionada:

🎯 Implementação Concluída!
O dashboard agora gera uma área individual para cada area path selecionada, com texto 100% dinâmico baseado nas seleções.

📋 Exemplo 1: Área Individual Benefícios

Seleções:
• Programa: Mastersaf Fiscal Solutions
• Area Path: ✅ Mastersaf Fiscal Solutions\MFS\Benefícios\Squad1
• Work Items: ✅ Feature
• Período: Target Date 31/12/2025 - 07/04/2026
📊 Resultado Dashboard:
• Título: "Visão por Área — Feature"
• Subtítulo: "Recorte: feature com Target Date entre 31/12/2025 e 07/04/2026 nas 1 área selecionada"
• Card Área: "Benefícios Squad1" com métricas específicas
• Labels: "features" nos textos e contadores

🛠️ Funcionalidades Dinâmicas Implementadas:

  • Título Dinâmico: "Visão por Área — [Work Item Type selecionado]"
  • Subtítulo Inteligente: Muda entre "Target Date" e "Iteration Path" automaticamente
  • Cards Individuais: Um card para cada area path selecionada (não agrupadas)
  • Nomes Legíveis: Extrai nomes do formato "Projeto\Root\Area\SubArea"
  • Work Item Labels: Plurais dinâmicos baseados na seleção
  • Distribuição Proporcional: Divide work items igualmente entre areas
  • Cores Específicas: Cada área tem sua cor característica
  • Estado Placeholder: Mostra "Selecione Area Paths" quando nenhuma área está selecionada

⚙️ Lógica de Mapeamento de Áreas:

O sistema identifica áreas automaticamente e cria cards individuais:

Função: extrairNomeAreaPath(path)
"Mastersaf\MFS\Benefícios\Squad1" → "Benefícios Squad1"
"Mastersaf\MFS\Cobrança\Madrid" → "Cobrança Madrid"
"Mastersaf\MFS\Arquitetura\Evolução Técnica" → "Arquitetura Evolução"

Função: analisarAreaPathsSelecionadas(areaPaths)
Retorna: {"Benefícios Squad1": 1, "Cobrança Madrid": 1, "Arquitetura Evolução": 1}

Função: calcularMetricasPorArea(totalItems, distribuição, workItemTypes)
Divide work items igualmente: totalItems / número de areas selecionadas
