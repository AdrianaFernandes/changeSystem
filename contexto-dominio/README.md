# Contexto Domínio

> **TR Change | Forge Enabler** — Mapa contextual de toda a documentação de domínio.

Este diretório organiza as documentações do Change Agent por **contexto de uso**, facilitando a navegação e o onboarding de novos Change Agents.

---

## Estrutura

```
contexto-dominio/
├── case/                # Identidade, modelo e posicionamento do Change Agent
├── analises/            # Ferramentas de diagnóstico e métricas
├── relatorios/          # Templates de reporte e acompanhamento
├── intervencoes/        # Planos de ação e padrões de intervenção
└── historico/           # Governança, rituais e evolução do sistema
```

---

## Navegação Rápida

| Contexto | O que contém | Link |
|---|---|---|
| **Case** | Playbook do Change Agent — identidade, pilares, modelo de operação, anti-padrões | [case/](case/) |
| **Análises** | Diagnóstico de vertical, métricas de fluxo, forecasting probabilístico | [analises/](analises/) |
| **Relatórios** | Delivery Follow-up, Feedback Loop, geração de PPTX | [relatorios/](relatorios/) |
| **Intervenções** | Plano de Ação com ondas de execução, linguagem de produto | [intervencoes/](intervencoes/) |
| **Histórico** | Rituais de governança, roadmap de evolução, cadências | [historico/](historico/) |

---

## Como usar

1. **Novo Change Agent?** Comece por [Case](case/) para entender o papel e o modelo.
2. **Iniciando em nova vertical?** Vá para [Análises](analises/) e aplique o diagnóstico.
3. **Cadência quinzenal?** Use [Relatórios](relatorios/) para o Delivery Follow-up.
4. **Problema identificado?** Estruture a resposta em [Intervenções](intervencoes/).
5. **Revisão de ciclo?** Consulte [Histórico](historico/) para rituais e evolução.
