# Delivery Follow-up — Dados

Aqui ficam os follow-ups publicados por todos os Change Agents.

## Como usar

1. Abra o [Delivery Follow-up](../delivery-follow-up.html) no navegador
2. Preencha os campos do periodo
3. Clique **Gerar PPTX** para baixar a apresentacao executiva
4. Clique **Publicar** para salvar aqui no repositorio
5. Clique **Historico** para ver e carregar follow-ups anteriores

Na primeira vez, clique **Config** e cole seu [GitHub Token](https://github.com/settings/tokens/new?scopes=repo&description=TR+Change+System).
