# Template de Plano de Ação

> **Thomson Reuters — TR Change | Forge Enabler**

---

## Como usar

Este template estrutura intervenções do Change Agent quando um problema requer ação coordenada. Preencha os blocos em sequência: contexto → objetivo → ações → ondas → governança → riscos.

**Quando usar:**
- Ao identificar um problema sistêmico no diagnóstico
- Quando um risco do Delivery Follow-up exige plano estruturado
- Para coordenar uma mudança de processo, papel ou cultura
