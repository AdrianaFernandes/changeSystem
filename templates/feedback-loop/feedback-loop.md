# Template de Feedback Loop

> **Thomson Reuters — TR Change | Forge Enabler**
> Versão 1.0 · Abril 2026

---

## Como usar

Este template estrutura a **retrospectiva trimestral de transformação**. O objetivo não é avaliar entregas individuais, mas refletir sobre o ciclo de transformação como sistema: o que evoluiu, o que estagnou, o que precisa mudar na abordagem.

**Cadência:** trimestral (ao final de cada quarter).
**Duração:** 60–90 min.
**Participantes:** Change Agent, Engineering Manager, representantes das squads.

**Preparação:** o Change Agent preenche os Blocos 1 e 2 **antes** da sessão com dados reais. Os Blocos 3 e 4 são preenchidos **durante** a sessão com a participação do time.
